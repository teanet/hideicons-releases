# HideIcons

Прячет выбранные иконки строки меню macOS и показывает их в своём меню: клик по 👁 открывает
список спрятанных иконок, выбор в нём открывает меню самой иконки. Поддерживаются macOS 26
и macOS 27 — механизмы скрытия у них разные, но пользоваться одинаково просто.

Здесь только сборки и список изменений, исходный код закрыт.

## Установка

1. Скачайте `HideIcons-<версия>.dmg` из [последнего релиза](https://github.com/teanet/hideicons-releases/releases/latest).
2. Откройте образ и перетащите HideIcons в «Программы».
3. Запустите HideIcons. В строке меню появится 👁, а Dock приложение не занимает.

Нужна macOS 26 или новее. Сборки подписаны Developer ID и нотаризованы Apple.
Интерфейс на русском и английском — по языку macOS.

## Разрешения

- **Универсальный доступ** — чтобы узнать, какому приложению принадлежит иконка, и нажать её.
  Без него в меню «Неизвестная иконка», и пункты неактивны.
- **Запись экрана** (только macOS 26) — для настоящих картинок иконок. Без неё в меню значки
  приложений. После выдачи утилиту нужно перезапустить. На macOS 27 не используется.

## Как пользоваться

### macOS 26

- Всё, что левее разделителя ‹, прячется. ⌥-клик (или правый клик) по 👁 показывает ‹ и спрятанные
  иконки, повторный — прячет обратно. Клик по самому ‹ тоже прячет.
- Иконки переставляются системным перетаскиванием с зажатой ⌘: что должно оставаться на виду —
  правее ‹, остальное — левее. Позиции запоминает сама macOS.
- При первом запуске ‹ стоит левее системных иконок, а секция раскрыта: ничего не пропадает, пока
  иконки не разложены. Новые иконки macOS ставит левее всех, так что они прячутся сами.
- С зажатой ⌥ меню 👁 переставляет иконки: строки спрятанных превращаются в «→ в строку меню»,
  а внизу появляются видимые иконки с «→ спрятать».

### macOS 27

Разделителя ‹ и ⌘-перетаскивания нет: прятать и возвращать иконки нужно через ⌥-меню 👁
(«→ спрятать» / «→ в строку меню»), а «Показать спрятанные в строке меню» временно показывает все.
Системные иконки (часы, Wi-Fi, батарея, Пункт управления) всегда остаются на месте. Картинки
в меню — иконки приложений: настоящий значок скрытой иконки на 27 снять нельзя.

### На обеих версиях

- Выбор иконки в меню 👁 на время показывает её и нажимает; когда её меню закроется, иконка
  прячется обратно. У иконок с обычным меню (iTerm2, трей Electron, VPN) оно открывается
  подменю при наведении.

## Приватность

Приложение ничего не отправляет в сеть. Настройки хранятся только на вашем Mac.
